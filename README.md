# se_contractholder

Paquete Node/TypeScript de contratos compartidos entre APIs del ecosistema. Exporta modelos y contratos para MS01, MS06, MS07, MS08, CH01 y tipos genéricos.

## Camino rápido

```bash
npm install
npm run tsc
```

Prueba local declarada:

```bash
npm test
```

## Contrato público

| Área | Valor |
|---|---|
| Paquete | `se_contractholder` |
| Tipo | Librería compartida Node/TypeScript |
| Main | `build/index.js` |
| Repositorio | `https://github.com/Dejavu75/se_contractholder` |

## Fuente de verdad

- Exports públicos: `index.ts`
- Familias exportadas: `MS01`, `MS06`, `MS07`, `MS08`, `CH01`, `Generic`
- Config TypeScript: `tsconfig.json`
